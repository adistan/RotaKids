# RotaKids Resolution 2026

This directory contains the official RotaKids Resolution 2026 and its supporting volumes, appendices, and working worksheet.

Each document is available in two formats:

- **Markdown (`.md`)** for accessibility, search, quotation, indexing, and automated analysis;
- **PDF (`.pdf`)** for the official formatted version.

## Reading Order

1. **Official Resolution 26R-xx** - the formal resolution text.
2. **Volume I - Documents 1-8** - the principal supporting documents.
3. **Volume II - Appendices** - supplementary materials and annexes.
4. **Worksheet** - the working and implementation document associated with the resolution package.

## Document Status

The PDF version preserves the official visual layout. The Markdown version is provided for accessibility and machine-readable use.
Where differences exist, the PDF version should be treated as the official formatted publication unless the document itself states otherwise.
