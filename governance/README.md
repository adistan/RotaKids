# RotaKids Governance Documents

This directory contains the core governance, safeguarding, branding, policy, and institutional reference documents of the RotaKids initiative.

Each document is available in two formats:

- **Markdown (`.md`)** for accessibility, search, quotation, indexing, and automated analysis;
- **PDF (`.pdf`)** for the official formatted version.
