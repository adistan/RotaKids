# RotaKids

Public repository and institutional archive of the RotaKids initiative.

This repository preserves the resolutions, governance documents, educational resources, reports, methodologies, and historical records developed within RotaKids.

Its purpose is not only archival. It is intended to ensure that the ideas, decisions, educational methods, and institutional work created through RotaKids remain publicly accessible, verifiable, reusable, and capable of being continued over time.

## Purpose

RotaKids supports the development of children and young people through education, civic responsibility, cooperation, community involvement, and practical projects.

This repository provides a stable public record of:
- resolutions;
- governance and organizational documents;
- educational resources and methodologies;
- reports and project results;
- public materials intended for reuse;
- historical versions of documents;
- materials supporting the long-term continuity of the initiative.

## Repository Structure

```text
rotakids/
├── README.md
├── [resolution/](/resolution) 
├── [governance/](/governance)
├── educational-materials/
├── reports/
├── public-resources/
└── archive/
```

### `[resolution/](/resolution)`

Contains the 2026 RotaKids resolution and its supporting documents.
The resolution is one of the central institutional documents of the initiative and should be treated as an authoritative reference according to the version and publication date indicated in the document.

### `[governance/](/governance)`

Contains governance rules, organizational principles, procedures, institutional documents, and materials concerning the administration and continuity of RotaKids.

### `educational-materials/`

Contains educational resources, guides, methodologies, activities, and materials intended for children, coordinators, teachers, volunteers, clubs, and partner organizations.

### `reports/`

Contains activity reports, project results, evaluations, statistical materials, and documents describing the development and impact of RotaKids.

### `public-resources/`

Contains materials intended for public communication, distribution, translation, adaptation, or reuse.

### `archive/`

Contains historical, superseded, or previous versions of documents.
Archived documents remain available for transparency and historical continuity but should not be treated as current unless explicitly stated.

## Document Status

Each important document should indicate, where applicable:
- title;
- version;
- publication date;
- document status;
- language;
- author or issuing body;
- applicable licence;
- whether it is current, superseded, draft, or archived.

The most recent published version should be considered authoritative unless the document itself states otherwise.

## File Formats

Documents may be published in more than one format:
- `PDF` for the visual version;
- `MD` or `TXT` for accessibility, indexing, search, quotation, and automated analysis;
- editable source formats where preservation or future revision is necessary.

Text versions are provided to make the repository accessible to search systems, researchers, educators, institutions, and artificial intelligence tools.

## Continuity

This repository is designed to preserve RotaKids beyond individual events, organizations, technical platforms, or project administrators.

The materials published here should remain:
- publicly accessible;
- versioned;
- traceable;
- reusable where licensing permits;
- understandable without dependence on a single website or individual;
- available for future educational and institutional development.

This repository therefore functions both as a public library and as a continuity mechanism for the RotaKids initiative.

- publication date;
- author or issuing body;

- permanent URL or release link.

## Licence

Documents intended for open reuse should include an explicit licence notice.
Software or technical source code, if added later, may be licensed separately from documents and educational materials.

## Disclaimer

This repository may contain documents, historical records, working materials, and archived versions.
The inclusion of a document in the repository does not automatically mean that it represents the current position of RotaKids.org.
Current status must be determined from the document version, publication date, directory, and status notice.
